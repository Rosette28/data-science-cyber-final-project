## Project Description

This project reproduces and critically evaluates the paper's progressive evaluation methodology, which trains ML models on CIC-IDS2017 and tests on the temporally later CSE-CIC-IDS2018 dataset to assess long-term IDS performance.

**Scope:** CIC-IDS2017 (train) → CSE-CIC-IDS2018 (test), binary classification, ~10% subsample, 6 models (DT, RF, SVM, NB, ANN, DNN).

### Paper's Key Claims
- SVM and ANN are most resistant to overfitting on the progressive test set.
- DT and RF overfit significantly (high in-distribution accuracy, large cross-dataset drop).
- ANN is best for long-term deployment; DT is best for resource-constrained environments.
- Progressive evaluation (training on an earlier dataset, testing on a later one) reveals overfitting that single-dataset cross-validation misses.
- 1:1 class balancing ("symmetry") is required for fair evaluation.

## About the Source Paper

**Problem:** Standard IDS evaluation trains and tests on data from the same time window, producing inflated accuracy that does not reflect how models degrade when deployed against evolving attacks and network environments.

**Proposed solution:** *Progressive evaluation* — train on CIC-IDS2017 (2017), test on CSE-CIC-IDS2018 (2018). The temporal gap between datasets simulates real deployment conditions.

**Datasets used:**
- **CIC-IDS2017** (~2.8M flows, 78 features, 15 attack types, 2017) — training set
- **CSE-CIC-IDS2018** (~16M flows, 80 features, some new attack types, 2018) — progressive test set
- **LUFlow** (2020–2021) — secondary experiment only

**Pipeline:** Preprocess (drop duplicates/inf/NaN, binary labels, 1:1 downsample) → Feature selection (RF importance + brute-force loop → 11 features) → GridSearchCV tuning (k=5 CV) → In-distribution eval → Progressive eval.

**Six models:** Decision Tree, Random Forest, SVM, Naïve Bayes, ANN (1 hidden layer), DNN (3 hidden layers).

**In-distribution results (CIC-IDS2017 test split):**

| Model | Accuracy |
|-------|----------|
| Random Forest | ~99.67% |
| Decision Tree | ~99.59% |
| DNN | ~97.35% |
| SVM | ~96.00% |
| ANN | ~95.49% |
| Naïve Bayes | ~72.96% |

**Key findings:**
- DT and RF achieve near-perfect in-distribution accuracy but suffer the largest drop on the 2018 progressive test — the paper interprets this as overfitting (though see critique below).
- SVM and ANN are most resistant to the cross-dataset performance drop.
- NB is the weakest model across all conditions, attributed to its feature-independence assumption being violated by correlated network features.

**Our critique (to be expanded in §2):** The paper conflates overfitting with concept drift; the 1:1 "symmetry" framing is arbitrary; NB's underperformance is asserted without a direct test; no statistical significance testing is reported; and the manual hyperparameter transfer step is a reproducibility hazard. Full notes in [`docs/paper_notes.md`](docs/paper_notes.md).

## Scope Decisions

- **Datasets:** CIC pair only (CIC-IDS2017 train → CSE-CIC-IDS2018 test). LUFlow is referenced but not reproduced.
- **Label type:** Binary (benign vs. malicious). Original attack-type labels kept for optional multiclass extension.
- **Subsample:** ~10% of each dataset, sampled while reading (chunked loading) to stay within Colab free-tier RAM.
- **Class balancing:** 1:1 downsample of majority class (mirroring the paper), plus a real-prevalence copy for imbalance analysis.
- **Models:** Decision Tree, Random Forest, SVM, Naïve Bayes, ANN (1 hidden layer), DNN (3–4 hidden layers).
